## Integer Factorization

Factorizing large integers is a central problem in number theory with crucial applications in cryptography. The challenge of integer factorization underpins the security of many cryptography systems. 
Consequently, the efficiency of integer factorization algorithms can have a significant impact on these systems' safety and reliability. This research aims to analyze the different solutions
to this problem. The research explores Trial Division, Pollard’s Rho Algorithm, Fermat’s Factorization, and Dixon Factorization Algorithm.
